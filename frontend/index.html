About DocSecure

Machine learning architectures and technical pipelines inside the Fake News Detector.

How the Pipeline Works

DocSecure converts raw news texts into numerical features utilizing advanced Term Frequency-Inverse Document Frequency (TF-IDF) transformations. Once vectorized, these mathematical signatures are evaluated against trained classifiers to compute classification labels and metrics.

Preprocessing

Punctuation cleanings, lowercasing, NLTK stopwords exclusion, and WordNet token lemmatization.

TF-IDF Features

Extracting unigrams and bigrams from cleaned text content to isolate unique vocabulary terms.

Ensemble Classifiers

Comparing Random Forests, SVMs, Naive Bayes, and Logistic Regression models to deploy the best pipeline.

Database Logging

Integrating transactions, file parsing, and classification outputs into secure SQLite databases.

System Blueprint

FastAPI Backend + SQLite + Chart.js + Bootstrap 5 Frontend. Designed for low latency inference and containerized environments.
